Clicked goes in flight for one round trip: LiveView disables it and shows "Working…" until the server replies, and the shell mirrors that wait onto aria-busy; it is announced but still wears the dimmed disabled look. Busy is the wait the server knows about, such as a sign-in that is opening the workspace: the control spins at full strength, is disabled and carries aria-busy. Disabled means the action is not available at all, so it dims and never spins.
