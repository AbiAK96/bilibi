Feedback, dialogs and tabs specimen

Flash, alert, panel notice, connection banners, modal and confirmation dialogs, and the tab strip. Dialogs and flashes are rendered by the server in production; here a small driver (ui-feedback-demo.js) stands in for the server by inserting and removing the same markup.

{% call ui::card(id="component-flash", title="Flash", inner_class="space-y-3 p-4") %}

One message per severity. Info, warning and error stay until dismissed; only a success times out, after eight seconds. Success and info are announced as a status; warning and error interrupt as an alert.

The two banners the browser reveals when the websocket drops: "Connection interrupted" while it cannot reach the server, "Server unavailable" when the server refused or lost the page. Shown here already revealed and bound to no connection event; the real pair is the flash group's at the top right, or an open dialog's.

An action that cannot be undone confirms here, never in the browser's own dialog. The dialog leads with the consequence, offers Cancel (which takes focus) and a calm danger confirm named by the verb, and Escape and Cancel are one action. The first row deletes; the second refuses because companies still use it.
